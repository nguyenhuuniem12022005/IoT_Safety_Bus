# IoT Safety Bus

Firmware ESP32-S3 cho mạch giám sát hành khách và cảnh báo người còn trên xe.

## Tệp chính

- [Firmware Arduino](esp32s3_bus_safety/esp32s3_bus_safety.ino)
- [Hướng dẫn nạp và sơ đồ GPIO](esp32s3_bus_safety/README.md)

Mở file `.ino` bằng Arduino IDE, chọn ESP32S3 Dev Module và cổng COM tương ứng để nạp.
